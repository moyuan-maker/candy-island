# 口语糖果岛 · 维护说明

Owner: moyuan (Chinese speaker; reply in Chinese, plain words, act first and ask only when blocked).
Product: a gamified English speaking app for women learners, sold as activation codes on 闲鱼 / 小红书.
Live site: https://moyuan-maker.github.io/candy-island/ (GitHub Pages serves `main`, repo root `index.html`).

## Layout
- `index.html` — built single-file web app (do not edit by hand; it is generated).
- `src/web.tpl.html` — web UI template (HTML/CSS/JS). Placeholders `/*@CONTENT@*/ /*@ENGINE@*/ /*@MASCOT@*/ /*@KEYS@*/`.
- `src/core/` — shared logic, used by both web and mini program:
  - `content.js` generated by `src/gen_content.py` from `src/data/` (200 phrases, gloss, 30 tips). 30 levels graded easy→hard by `grade.py`; 5 stages 巴黎→纽约→东京→伦敦→主角时刻.
  - `engine.js` step builder (learn / choose / build / fill / act / match), scoring, stars, badges, state.
  - `mascot.js` the 糖豆 mascot SVG.
  - `keys.js` SHA-256 (first 12 hex) of every valid activation code. Real codes are NOT in this repo.
- `miniprogram/` — native WeChat mini program (WechatSI plugin for TTS/ASR). `miniprogram/utils/content.js` and `engine.js` must stay identical copies of `src/core/`.
- `src/pdf/build.js` — renders the 35-page PDF from `src/data/data.txt` (node + playwright).
- `promo/` — 小红书 promo slides (`slides.html`, `render.js`) and app screenshots.
  - `promo/video/` — batch 小红书 vertical videos: `specs.js` (one entry per video: hook, shots, captions), `stage.html` (frame), `rec.js` (plays the real app in an iframe, CDP screencast → ffmpeg mp4). Run from repo root: `python3 -m http.server 8765 &` then `cd promo/video && NODE_PATH=$(npm root -g) node rec.js [id-prefix]`.
  - `promo/notes/` — 30-day image notes (`card.html?day=N`, `render.js`) and posting copy (`node copy.js > 发布清单.md`). Same server needed.
- `src/test/` — playwright scripts (run from `src/` after building; `NODE_PATH=$(npm root -g) node test/test.js`).

## Common tasks
- Rebuild after any change: `cd src && python3 gen_content.py && python3 build.py` (writes `src/index.html` for tests and `../index.html` for Pages), then copy `src/core/content.js engine.js` into `miniprogram/utils/`, commit, push `main`.
- Paywall: levels 1–3 free (`FREE` in `web.tpl.html`), the rest need a code `TANG-XXXX-XXXX-XXXX`.
- Revoke a leaked code: add its hash (`sha256(code without TANG and dashes, uppercase)[:12]`) to `REVOKED` in `web.tpl.html`, rebuild, push. Devices already activated with it get locked on next open.
- New code batch: generate random 12-char codes from alphabet `23456789ABCDEFGHJKMNPQRSTUVWXYZ`, append their hashes to `KEYS`, and give the plain codes to moyuan privately (project files folder `口语糖果岛/闲鱼销售/`). Never commit plain codes.
- Not done yet: binding a code to one device needs a server (plan: free Cloudflare Worker + KV, needs moyuan's account).
