# 口语糖果岛 · 微信小程序版

和网页版是同一个产品：30 关闯关、糖豆陪练、跟读打分、糖果消消乐、毕业封面大片。

## 上线步骤（不用写代码）

1. **下载微信开发者工具**：搜索「微信开发者工具」，从微信官方网站下载并安装，用微信扫码登录。
2. **导入项目**：点「导入」，目录选**这个文件夹**（口语糖果岛小程序）。
3. **填 AppID**：
   - 先注册小程序（mp.weixin.qq.com → 立即注册 → 小程序），在后台「开发管理 → 开发设置」里复制 AppID，填进去。
   - 本项目里写的 `touristappid` 只是占位。**测试号/游客模式用不了插件**，会提示「插件未授权」。如果只想先看看界面，可以临时删掉 `app.json` 里的 `"plugins": {...}` 那一段：界面都能用，但没有朗读，跟读会变成自评。
4. **添加语音插件**：小程序后台 →「设置 → 第三方设置 → 插件管理」→ 添加插件，搜索「**微信同声传译**」并添加。它负责英文朗读和跟读识别。
5. **填写隐私保护指引**：后台「设置 → 服务内容声明 → 用户隐私保护指引」，勾选：**麦克风**（跟读打分）、**相册（仅写入）**（保存封面/打卡图）、**选中的照片或视频**（封面换成自己的照片）。
6. **预览**：开发者工具点「预览」，用手机扫码试玩（跟读要在真机上试）。
7. **上传 → 提交审核**：点「上传」，填版本号；再到后台「版本管理」提交审核。
   - 类目建议选「教育 > 在线教育」或「教育 > 教育信息服务」等。**个人主体能选的类目有限**，具体以后台显示为准，有的类目需要资质。

## 文件说明

- `pages/index`：旅程地图 / 30天后的我 / 我的收藏（底部三个标签）+ 第一次打开的欢迎页
- `pages/lesson`：闯关（跟读、听音选意、糖果拼句、填空、演技挑战、消消乐）和结算
- `pages/grad`：毕业提词器 + 「SHE SPEAKS」杂志封面
- `utils/content.js`、`utils/engine.js`：**课程内容和游戏规则**，和网页版完全相同。原件在 `口语糖果岛共用内容/`，以后改内容只改那里，再复制到网页版和这里的 `utils/` 即可。
- `images/`：糖豆的 6 个表情
